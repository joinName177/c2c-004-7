# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比和双投影视图联动
- 超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- 分段行程规划：每段独立的可用尺寸与重量上限，物品按“从哪段携带到哪段”参与装箱
- 相邻路段交接清单（取出 / 新增 / 需要重排），必带物品前段未装入则后段不会凭空出现
- 某段无解时保留其他段结果，但整趟不显示可出发；修改行程后需重新检查，已确认的旧路线保留到接受新结果才替换
- localStorage 本地保存与打印清单

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 分段行程

`src/core/trip-service.ts` 在单段装箱引擎之上编排整趟行程：每段用自己的尺寸与限重独立装箱，物品按携带区间（`carryFrom` / `carryTo`）参与对应路段。相邻两段由交接清单描述取出、新增与需要重排的物品；必带物品一旦在某段装不下，后续段会被排除并标记“前段未装入”，不会凭空出现。任何一段出现严重风险时整趟 `ready` 为 false。界面层保留“已确认路线”和“待确认草稿”两份结果，修改行程后需手动重新检查，接受草稿才替换旧路线。
